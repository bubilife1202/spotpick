## 2. 수정 방향

### 핵심 원칙: "3 클릭으로 끝나는 창업 분석"

```
[Step 1] 업종 + 예산 입력  →  [Step 2] AI 원페이지 리포트  →  [Step 3] 사업계획서 + PDF
         /analyze                   /analyze/report                 /analyze/action
```

- **매물/비용비교는 리포트 내 섹션으로 통합** (별도 페이지 X)
- **5단계 → 3단계로 복원**
- **모든 "상세 보기"는 페이지 내 스크롤 또는 같은 보고서 내에서 해결**

## 3. 구체적 수정 사항

### 3-1. 랜딩 페이지 대수술

**삭제할 섹션:**
- ~~LiveDemoSection~~ (라이브 데모) → 삭제. /analyze로 바로 유도
- ~~EntryPointSection~~ (6개 진입점) → 삭제. 선택지 과다
- ~~ComparisonSection~~ (오픈업/ChatGPT 비교) → 삭제. 베타 단계에서 불필요

**유지/수정 섹션:**

| 섹션 | 수정 내용 |
|------|----------|
| **HeroSection** | 통계 리프레이밍: "10개 업종" → "외식업 전 업종", "7종 공공데이터" → "7대 공공 빅데이터" |
| **PipelineSection** | 3단계 유지 (일관성 확보) |
| **PricingSection** | 유지 |
| **Header** | 네비 5개 → **0개** (시작하기 버튼만 남김). 베타 단계에서 네비 불필요 |
| **Footer** | 유지 |

**수정 후 랜딩 구조:**
```
Header (로고 + "무료로 시작하기" CTA만)
  ↓
HeroSection (히어로 + 통계)
  ↓
PipelineSection (3단계 파이프라인)
  ↓
PricingSection (요금제 — 베타 무료)
  ↓
Footer
```

### 3-2. 분석 입력 페이지 (`/analyze`) 개선

| 항목 | 현재 | 수정 |
|------|------|------|
| 예산 프리셋 | "3천~5천만원" (텍스트) | 그대로 유지 (충분히 명확) |
| 직접입력 라벨 | "최소 (만원)" 작은 글씨 | **입력란 오른쪽에 "만원" suffix** 추가 |
| 직접입력 값 | 3000 (bare number) | 그대로 + suffix "만원" 으로 단위 명확화 |
| 스테퍼 | 5단계 | **3단계로 복원** |

### 3-3. 리포트 페이지 (`/analyze/report`) 핵심 수정

#### (A) TOP 3 카드 개선

**현재**: 종합점수/생존율/월매출/경쟁점포 — 설명 없이 숫자만
**수정**:

```
┌─────────────────────────────┐
│  1위 🏆  포이사거리(삼호물산) │
│  발달상권        [추천]      │
│                              │
│  AI 종합 점수     75.8/100  │ ← "5대 지표 가중 평균"
│  2년 생존율      100%       │ ← "최근 2년 폐업 없음"
│  카페 월 매출    5,618만원   │ ← "이 상권 카페 평균 카드매출"
│  카페 점포 수    2개         │ ← "현재 영업 중인 카페"
└─────────────────────────────┘
```

변경점:
- **업종명 명시**: "월매출" → "{업종} 월 매출", "경쟁점포" → "{업종} 점포 수"
- **메트릭 설명 추가**: 각 메트릭 아래에 한 줄 설명
- **"생존율"** → **"2년 생존율"** (기간 명시)

#### (B) TOP 3 지도 항상 표시

**현재**: `districts.some((d) => d.coordinates)` 조건부 → 좌표 없으면 숨김
**수정**:
- 백엔드 `recommendations/dashboard`에서 항상 좌표 반환 (district_coords.json 활용)
- 프론트에서 좌표 없으면 기본 서울 중심 좌표 사용
- **지도를 TOP 3 카드 위에 배치** (현재는 아래)

#### (C) 업종 컨텍스트 명시

**현재**: 리포트 상단에 작은 글씨 "카페 / 예산 3만~10만원"
**수정**:
```
┌────────────────────────────────────────┐
│  ☕ 카페 창업 분석 리포트               │
│  예산 3,000만 ~ 1억원                   │
│  서울 1,077개 상권 중 AI 추천 TOP 3     │
└────────────────────────────────────────┘
```
- 업종 아이콘 + 이름을 리포트 제목에 포함
- 각 섹션 제목에도 업종 반영: "B3. 경쟁 환경" → "B3. 카페 경쟁 현황"

#### (D) "상세 보기" 링크 수정

| 위치 | 현재 링크 | 수정 |
|------|----------|------|
| B1 스코어카드 "상세 스코어카드 보기" | `/report?...` (레거시) | **삭제** (이미 리포트 안에 있음) |
| B2 수익 "상세 시뮬레이터" | `/simulator?...` | **페이지 내 C섹션으로 스크롤** |
| B7 프랜차이즈 "프랜차이즈 상세 비교" | `/franchise?...` | **삭제** (리포트에 충분) |
| E 지원금 "전체 지원금 보기" | `/support?...` | **삭제** 또는 유지 (선택) |
| 랜딩 데모 "이 상권 상세 분석" | `/report?...` (레거시) | **삭제** (라이브 데모 섹션 자체 삭제) |

#### (E) 빈 데이터 문제 해결

| 문제 | 원인 | 해결 |
|------|------|------|
| "조건에 맞는 상권이 없습니다" | 예산 필터 `rent > budget_max` | **백엔드**: 예산 필터 완화. 항상 최소 TOP 3 반환. 예산 초과 시 경고 배지만 표시 |
| B7 "프랜차이즈 데이터를 불러올 수 없습니다" | `/franchise/benchmark/{code}` 빈 응답 | **백엔드**: 업종별 기본 프랜차이즈 데이터 확보 또는 "해당 업종 프랜차이즈 정보 준비 중" 안내 |
| D "분석 데이터 없음" | Gemini API 응답 파싱 실패 | **프론트**: `sections` 배열 매칭 로직 개선 + 폴백 텍스트 추가 |
| 예산 표시 버그 | `budgetMin / 10000 * 10000 / 10000` | **수정**: `budgetMin.toLocaleString()` + "만원" |

### 3-4. 스테퍼 3단계 복원

**현재 (5단계):**
```
[입력] → [리포트] → [매물] → [비교] → [액션]
```

**수정 (3단계):**
```
[입력] → [AI 리포트] → [액션 플랜]
```

- `analyze-store.ts`: `AnalyzeStep = 1 | 2 | 3`
- `AnalyzeStepper.tsx`: 3개 아이콘 (ClipboardList, FileBarChart, Rocket)
- `/property`, `/cost-compare` 페이지는 **삭제하지 않고** 리포트에서 옵션 링크로만 접근

### 3-5. 리포트 하단 CTA 정리

**현재** (4개 버튼):
```
[매물 찾아보기] [비용 비교하기] [창업 타임라인] [사업계획서 생성]
```

**수정** (1개 메인 + 2개 보조):
```
[사업계획서 생성하기]  ← 메인 CTA (Step 3로 이동)

[매물 탐색] [비용 비교]  ← 선택 옵션 (작은 링크)
```

## 7. 요약

**Before**: 5단계 워크플로, 6개 진입점, 설명 없는 메트릭, 레거시 링크, 빈 데이터
