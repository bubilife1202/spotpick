### 2.3 Redis 캐싱 (P2)

**현재 문제**: 동일 질문에 반복 API 호출

**목표**: 응답 캐싱으로 비용/속도 개선

```python
import redis
import hashlib

redis_client = redis.Redis()

async def get_cached_response(query: str, history: list) -> str | None:
    key = hashlib.md5(f"{query}:{history}".encode()).hexdigest()
    return await redis_client.get(f"chat:{key}")

async def cache_response(query: str, history: list, response: str):
    key = hashlib.md5(f"{query}:{history}".encode()).hexdigest()
    await redis_client.setex(f"chat:{key}", 3600, response)  # 1시간 캐시
```
