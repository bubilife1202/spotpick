## Part 2. 기술적 압도 — AI 네이티브 극대화

### 2-1. AI 아키텍처 업그레이드

```
현재 (v0.9.1):
┌──────────┐     ┌──────────┐     ┌──────────┐
│ 사용자    │ ──▶ │ API 서버  │ ──▶ │ Gemini   │
│ (입력)   │     │ (데이터)  │     │ (생성)   │
└──────────┘     └──────────┘     └──────────┘
→ 문제: AI가 "한 번 생성하고 끝". 피드백 루프 없음.

목표 (v1.0.0):
┌──────────┐     ┌──────────┐     ┌──────────┐
│ 사용자    │ ◀─▶ │ AI Agent │ ◀─▶ │ Gemini   │
│ (대화)   │     │ (오케스트)│     │ (추론)   │
└──────────┘     │          │     └──────────┘
                 │          │     ┌──────────┐
                 │          │ ◀─▶ │ 데이터    │
                 │          │     │ (1,077)  │
                 └──────────┘     └──────────┘
→ AI Agent가 사용자 의도를 파악 → 필요한 데이터 자동 조회 → 분석 → 추천 → 검증 → 재추천
```

### 2-2. Agent Loop 구현

```python
# ai_agent_service.py (신규)

class StartupAgent:
    """창업 의사결정 AI 에이전트 — 데이터 기반 자율 분석"""

    TOOLS = [
        "search_districts",      # 상권 검색
        "get_scorecard",         # 스코어카드 조회
        "run_simulation",        # 수익 시뮬레이션
        "compare_districts",     # 상권 비교
        "find_support_programs", # 지원금 매칭
        "analyze_competition",   # 경쟁 분석
        "check_risk",           # 위험도 분석
        "generate_timeline",    # 타임라인 생성
    ]

    async def run(self, user_query: str, context: dict) -> AgentResponse:
        """
        사용자 질문 → Tool 선택 → 데이터 조회 → 분석 → 응답
        최대 5회 반복 (자율 판단으로 추가 데이터 필요시 재조회)
        """
        messages = [{"role": "user", "content": user_query}]

        for step in range(5):  # 최대 5단계 자율 루프
            response = await self.gemini.generate(
                messages=messages,
                tools=self.TOOLS,
                context=context
            )

            if response.tool_calls:
                # AI가 스스로 필요한 데이터를 판단하여 조회
                tool_results = await self.execute_tools(response.tool_calls)
                messages.append({"role": "assistant", "content": response})
                messages.append({"role": "tool", "content": tool_results})
            else:
                # 충분한 데이터를 모았으면 최종 응답
                return response

        return response  # 5단계 이내 완료
```

```python
# api/services/risk_service.py (신규)

class RiskService:
    """폐업 위험 신호 탐지 서비스"""

    RISK_THRESHOLDS = {
        "survival_rate": 0.60,        # 생존율 60% 미만 = 위험
        "competition_density": 80,     # 동종 점포 80개 이상 = 과밀
        "rent_to_sales_ratio": 0.25,   # 임대료/매출 25% 이상 = 위험
        "growth_rate": -0.10,          # 매출 성장률 -10% 이하 = 하락
        "new_store_surge": 0.30,       # 신규 점포 30% 이상 급증 = 과열
    }

    def analyze_risk(self, district_data: dict, industry_code: str) -> dict:
        signals = []
        risk_score = 0

        # 1. 생존율 체크
        survival = district_data.get("survival_rate", 0)
        if survival < self.RISK_THRESHOLDS["survival_rate"]:
            signals.append({
                "level": "danger",
                "title": "높은 폐업률",
                "detail": f"동종업종 폐업률 {(1-survival)*100:.0f}% (서울 평균 22%)",
                "advice": "경쟁이 심하고 수요가 줄고 있습니다"
            })
            risk_score += 25

        # 2. 경쟁 밀도 체크
        store_count = district_data.get("store_count", 0)
        if store_count > self.RISK_THRESHOLDS["competition_density"]:
            signals.append({
                "level": "danger",
                "title": "경쟁 과밀",
                "detail": f"반경 내 동종 점포 {store_count}개",
                "advice": "차별화 전략 없이는 생존이 어렵습니다"
            })
            risk_score += 20

        # 3. 임대료 대비 매출 비율
        rent = district_data.get("estimated_rent", 0)
        sales = district_data.get("monthly_sales", 1)
        rent_ratio = rent / sales if sales > 0 else 1
        if rent_ratio > self.RISK_THRESHOLDS["rent_to_sales_ratio"]:
            signals.append({
                "level": "danger",
                "title": "과도한 임대 부담",
                "detail": f"임대료/매출 비율 {rent_ratio*100:.0f}% (권장: 15% 이하)",
                "advice": "고정비 부담이 과도합니다"
            })
            risk_score += 20

        # 4. 매출 성장률
        growth = district_data.get("growth_rate", 0)
        if growth < self.RISK_THRESHOLDS["growth_rate"]:
            signals.append({
                "level": "warning",
                "title": "매출 하락 추세",
                "detail": f"전년 대비 매출 {growth*100:+.0f}%",
                "advice": "상권이 쇠퇴하고 있을 수 있습니다"
            })
            risk_score += 15

        # 5. 신규 점포 급증
        new_store_rate = district_data.get("new_store_rate", 0)
        if new_store_rate > self.RISK_THRESHOLDS["new_store_surge"]:
            signals.append({
                "level": "warning",
                "title": "신규 점포 급증",
                "detail": f"신규 개업 {new_store_rate*100:.0f}% 증가 (YoY)",
                "advice": "시장이 과열 상태입니다"
            })
            risk_score += 15

        return {
            "risk_score": min(risk_score, 100),
            "risk_level": "high" if risk_score >= 60 else "medium" if risk_score >= 30 else "low",
            "signals": signals,
            "signal_count": len(signals),
        }
```

### 7-5. 애널리틱스 시스템

```typescript
// web/src/lib/analytics.ts (신규)

type EventName =
  | "page_view"
  | "journey_start"
  | "industry_select"
  | "district_select"
  | "report_view"
  | "compare_start"
  | "compare_complete"
  | "risk_alert_view"
  | "simulation_run"
  | "support_match"
  | "timeline_generate"
  | "plan_generate"
  | "plan_download"
  | "chat_message"
  | "feedback_submit"
  | "journey_complete";

const API_BASE = process.env.NEXT_PUBLIC_API_URL || "/api/v1";

let sessionId: string | null = null;
function getSessionId(): string {
  if (!sessionId) {
    sessionId = `${Date.now()}-${Math.random().toString(36).slice(2, 8)}`;
  }
  return sessionId;
}

export function track(name: EventName, props?: Record<string, string | number>) {
  if (typeof window === "undefined") return;

  const payload = {
    event: name,
    session_id: getSessionId(),
    timestamp: new Date().toISOString(),
    page: window.location.pathname,
    referrer: document.referrer,
    user_agent: navigator.userAgent,
    props: props || {},
  };

  // sendBeacon for reliability (works even on page close)
  const blob = new Blob([JSON.stringify(payload)], { type: "application/json" });
  navigator.sendBeacon?.(`${API_BASE}/analytics/event`, blob)
    || fetch(`${API_BASE}/analytics/event`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(payload),
      keepalive: true,
    }).catch(() => {});
}
```

## Part 9. 핵심 요약 — "왜 SpotPick이 압도적인가"

### 경쟁사 대비 SpotPick v1.0.0 포지셔닝

```
                 데이터 정확도
                     ▲
                     │
                     │       ★ SpotPick v1.0.0
                     │       (실데이터 + AI Agent + 원스톱)
                     │
      오픈업 ●       │
      (데이터만)     │
                     │
                     ├──────────────────────────▶ AI 활용도
                     │
                     │              ● ChatGPT
                     │              (AI만, 데이터 없음)
                     │
```

### 원스톱 워크플로우 — 경쟁사 흡수 완료

```
1. "뭘 할까?" ────── ChatGPT 대체 ──── AI 상담 + 업종 추천
2. "프랜차이즈?" ─── 공정위 직접 검색 대체 ── 프랜차이즈 비교
3. "어디서?" ──────── 오픈업 대체 ────── AI 입지 추천 (1,077개)
4. "괜찮은 곳?" ──── 네이버지도 대체 ─── 상권 비교 + 폐업 경보
5. "얼마나?" ──────── 세무사 대체 ────── 수익 시뮬레이션
6. "도움 받을 곳?" ── 소상공인마당 대체 ── 지원금 23개 자동 매칭
7. "언제 시작?" ──── 없음 (SpotPick만) ── 창업 타임라인
8. "서류 만들기" ─── 없음 (SpotPick만) ── AI 사업계획서 PDF
9. "인허가?" ──────── 없음 (SpotPick만) ── 인허가 체크리스트
```

**결론**: SpotPick v1.0.0은 창업자가 사용하는 6개 이상의 서비스를 **하나의 플랫폼으로 통합**. 어떤 경쟁사도 이 범위를 커버하지 못함. **AI 네이티브 + 실데이터 + 원스톱 = 압도적 경쟁력.**
